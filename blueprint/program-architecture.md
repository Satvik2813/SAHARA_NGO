# SAHARA — Programs Architecture

**Phase 2.** How to present SAHARA's programs, separating **current**, **historical**, and **needs-verification** — per the audit's explicit warning not to present discontinued/historical programs as current.

Legend: **[Client] [Web] [WP] [Verify]**. Status = **Current** (consistent across recent sources) · **Historical** (documented but not confirmed recent) · **[Verify]**.

> **Client-confirmation note (2026-08-09):** the client provided **no new/updated program list** and instructed us to **use the audited source material** and **not invent programs**. This architecture therefore stands as-is. Where a program's *current* status can't be established from the sources, label it **[Needs careful content wording]** and **do not assert "currently active."** The six core areas are supported across client material + current site + history; the historical/wider-history set stays framed as history until the client confirms otherwise. (Photo/story **consent is now granted**, so program photos may be used.)

---

## Presentation model

- **Six current core programs** shown as equal, first-class areas on `/our-work` (anchored sections; can split into pages later if depth grows).
- Each program block: **Name · One-line promise · Description (what) · How we do it · Where/place detail · Who it helps · Photo(s) · Related story · Giving CTA · Status label.**
- **Historical initiatives** shown in a clearly separate "**Where we've also worked / Our wider history**" strip (or on `/journey`), never mixed into "what we do now."
- **Discontinued-but-notable** items (e.g. child-labour special schools, orphanage support, agri/rural development, HIV/AIDS) appear as **history**, tagged historical, until the client confirms current status.

## The six current core programs (consistent across Writeup + PPTs + current site)

- **Promise (proposed):** "Every child deserves a chance to learn and dream." [Client Writeup]
- **Description:** Support for disadvantaged children — orphan, semi-orphan, poor **girl children**, single-parent children — to stay in school: educational materials, tuition fees, nutrition, clothing, toiletries, healthcare, emergency needs; support for higher education [Client/Web/WP].
- **Notable model:** **"Paying It Back"** — former beneficiaries now donate [Client PPT1].
- **Source:** `Writeup.txt`, PPT1 (120 enrolled; ~30 higher-ed), reports (per-year counts) [Client/WP].
- **Visual:** `2.jpg`, `bags.JPG`, `41 (2).JPG`, `child 2.22.JPG` [Client].

### 2. Elderly Care — **Current**

- **Notable:** **Suraksha Old Age Home / Day-Care Centre** (Ashok Nagar, near BHEL) [WP] — **[Verify]** still operating.
